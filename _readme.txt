Keys to use:

mouse - point what direction to move
left mouse button - fire weapon, select upgrade, navigate menu and shop
A - move left
D - move right
W - jump
space - jump
Q - select gun element (only available after clearing the first room)
E - open chest
R - reload gun

Special instructions:
The final boss is on the fifth floor, so to see as much game content as possible in a limited time, exit each room to the top
